## ❓ Ответы на контрольные вопросы

### 1️⃣ Какие программы используют для тестирования видеокарт?

```
🔹 3DMark — эталонный бенчмарк с тестами:
   • Time Spy (DirectX 12)
   • Fire Strike (игровая производительность)
   • Port Royal (трассировка лучей)

🔹 Unigine Superposition / Heaven — 
   стресс-тесты в сложных 3D-сценах с поддержкой 
   современных графических технологий

🔹 MSI Afterburner / EVGA Precision X1 — 
   мониторинг в реальном времени + разгон

🔹 OCCT — комплексная диагностика с акцентом 
   на выявление артефактов и перегрева

🔹 Valley Benchmark — визуально насыщенный тест 
   на движке Unigine для оценки стабильности
```

### 2️⃣ Какие программы используют для тестирования мониторов?

```
🔹 EIZO Monitor Test — профессиональный набор 
   для оценки цветопередачи, градиентов, углов обзора

🔹 Dead Pixel Tester — быстрое выявление 
   дефектных пикселей через циклическую смену цветов

🔹 Nokia Monitor Test — классическая утилита 
   для проверки геометрии, фокусировки, контраста

🔹 Online-сервисы (tft.vanity.dk, eizo.com/monitor-test) — 
   браузерные тесты без установки ПО

🔹 DisplayCAL — калибровка цвета и проверка 
   равномерности подсветки
```
