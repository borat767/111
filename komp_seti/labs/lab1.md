### Теоретическая справка

Для технологии Ethernet используется топология "звезда" с концентратором в центре, причем определены порты типа MDI (Medium Depended Interface, разъем сетевого адаптера) и MDIX (MDI crossing, разъем портов сетевого концентратора).

## 5. Ответы на контрольные вопросы

## 1. Какие сетевые кабели использует технология Ethernet? Что такое кабель UTP? В чем его достоинства и недостатки?

**Типы кабелей в Ethernet:**
Технология Ethernet использует преимущественно кабели на основе **витой пары** (Twisted Pair), а также оптоволоконные кабели. Наиболее распространены кабели категорий:
- **Cat5e** — до 1 Гбит/с, частота до 100 МГц [[1]]
- **Cat6** — до 10 Гбит/с (на расстоянии до 55 м), частота до 250 МГц
- **Cat6a** — до 10 Гбит/с на 100 м, частота до 500 МГц
- **Cat7/Cat8** — для высокоскоростных магистральных соединений

**UTP-кабель** (Unshielded Twisted Pair) — неэкранированная витая пара, состоящая из изолированных медных проводников, скрученных попарно и заключённых в общую внешнюю оболочку [[9]].

| Достоинства | Недостатки |
|------------|-----------|
|  Низкая стоимость по сравнению с экранированными аналогами [[5]] |  Высокая чувствительность к электромагнитным помехам (EMI/RFI) [[4]] |
|  Простота монтажа и гибкость — не требует заземления [[9]] |  Отсутствие физической защиты от перехвата сигнала [[9]] |
|  Лёгкий вес и компактность — удобен для прокладки в ограниченном пространстве [[8]] |  Ограниченная длина сегмента (до 100 м) из-за затухания сигнала [[6]] |
|  Широкая совместимость с сетевым оборудованием |  Не рекомендуется для промышленных зон с высоким уровнем помех |

## 2. Что такое сетевые устройства MDI и MDIX? Для соединения каких устройств необходим "перекрестный" (кроссированный) кабель?

**MDI** (Medium-Dependent Interface) — тип порта на оконечных устройствах (ПК, серверы, рабочие станции), где контакты 1,2 используются для передачи (Tx), а 3,6 — для приёма (Rx) [[13]].

**MDIX** (Medium-Dependent Interface Crossover) — тип порта на коммутаторах и концентраторах, где назначение контактов инвертировано: 1,2 — приём, 3,6 — передача [[14]].

**Когда нужен кроссовер-кабель:**
| Тип соединения | Тип кабеля |
|---------------|-----------|
| ПК ↔ Коммутатор/Хаб | Прямой (straight-through) |
| ПК ↔ ПК | **Кроссовер** (crossover) [[58]] |
| Коммутатор ↔ Коммутатор | **Кроссовер** |
| Хаб ↔ Хаб | **Кроссовер** |

>  **Важно:** Современные устройства стандарта Gigabit Ethernet и выше поддерживают **Auto-MDI/MDIX** — автоматическое определение типа подключения, поэтому кроссовер-кабели практически не требуются [[15]][[59]].

## 3. Почему при монтаже вилки RJ-45 на кабель нет необходимости снимать изоляцию с отдельных жил кабеля?

При обжиме разъёма RJ-45 используется технология **Insulation Displacement Contact (IDC)** — контакт, прорезающий изоляцию [[22]][[26]].

**Принцип работы:**
1. Золотые контакты внутри коннектора имеют острые режущие кромки
2. При обжиме кримпером контакты продавливают изоляцию жил и обеспечивают электрический контакт с медным проводником [[64]]
3. Предварительное снятие изоляции может привести к:
   - Ослаблению механической фиксации жилы
   - Окислению оголённого провода
   - Нарушению целостности соединения при вибрации

**Требования к монтажу:**
- Общая внешняя изоляция кабеля должна заходить под фиксатор разъёма для механической прочности [[65]]
- Жилы должны упираться в переднюю стенку коннектора
- Цветовая схема (T568A или T568B) должна соблюдаться на обоих концах кабеля

## 4. Что такое "нуль-модемный" кабель и для каких целей он применяется?

**Нуль-модемный кабель** — специальный последовательный кабель для соединения двух устройств класса DTE (Data Terminal Equipment) по интерфейсу RS-232 **без использования модема** [[34]].

**Особенности разводки:**
- Линия передачи (TxD) одного устройства соединяется с линией приёма (RxD) другого — «крест-накрест» [[32]]
- Сигналы управления (RTS/CTS, DTR/DSR) также коммутируются соответствующим образом
- Существуют упрощённые схемы (3 провода: TxD↔RxD, RxD↔TxD, GND↔GND) для ПО без контроля потока

**Области применения:**
| Применение | Описание |
|-----------|----------|
|  Настройка сетевого оборудования | Консольное подключение к коммутаторам/маршрутизаторам через COM-порт [[36]] |
|  Передача файлов | Прямое соединение двух ПК для обмена данными (актуально в 1980–90-х) [[39]] |
|  Сетевые игры | Многопользовательские игры через COM-порты (Doom, WarCraft II) [[34]] |
|  Подключение периферии | Связь с промышленным оборудованием, терминалами, принтерами |

>  В современных системах нуль-модемные соединения эмулируются программно (виртуальные COM-порты) или заменяются USB/Ethernet-адаптерами.

## 5. Каким образом однозначно идентифицируются сетевые адаптеры? С какой целью введена возможность изменения MAC-адреса?

**Идентификация адаптеров:**
Каждый сетевой адаптер имеет уникальный **MAC-адрес** (Media Access Control) — 48-битный аппаратный идентификатор, «прошитый» производителем [[47]].

Формат: `XX:XX:XX:XX:XX:XX` (шестнадцатеричный), например: `00:1A:2B:3C:4D:5E`
- Первые 24 бита (OUI) — идентификатор производителя
- Последние 24 бита — уникальный номер устройства

**Назначение MAC-адреса:**
- Уникальная идентификация узла в широковещательных сетях (Ethernet, Wi-Fi) [[48]]
- Маршрутизация кадров на канальном уровне модели OSI
- Работа протоколов ARP/NDP для сопоставления с IP-адресами

**Зачем менять MAC-адрес?**
| Причина | Описание |
|---------|----------|
|  Конфиденциальность | Сокрытие реального адреса устройства в публичных сетях [[42]] |
|  Обход привязки у провайдера | Клонирование разрешённого MAC-адреса для доступа в Интернет [[44]] |
|  Тестирование и отладка | Эмуляция нескольких устройств с одного физического адаптера |
|  Замена оборудования | Временное использование адреса вышедшего из строя устройства |

>  Изменение MAC-адреса возможно программно (через реестр Windows, утилиты `macchanger` в Linux), но не отменяет заводской адрес, хранящийся в ПЗУ адаптера [[40]][[45]].

## 6. В чем заключается процесс конфигурирование сетевой платы? Какие параметры при этом настраиваются?

**Процесс конфигурирования** включает настройку параметров сетевого адаптера на программном и аппаратном уровнях для обеспечения корректной работы в сети.

**Основные настраиваемые параметры:**

| Группа параметров | Конкретные настройки |
|------------------|---------------------|
|  **IP-конфигурация** | • Статический IP-адрес / получение по DHCP [[49]]<br>• Маска подсети, шлюз по умолчанию, DNS-серверы |
|  **Аппаратные настройки** | • Скорость и дуплекс (10/100/1000 Мбит, Full/Half) [[52]]<br>• Включение/отключение Auto-MDI/MDIX, Flow Control |
|  **Безопасность** | • Фильтрация по MAC-адресам, 802.1X-аутентификация |
|  **Производительность** | • Размер буферов, отключение энергосберегающих режимов (EEE)<br>• Offload-функции (TCP checksum, LSO, RSS) [[52]] |
|  **Дополнительно** | • Изменение MAC-адреса (NetworkAddress)<br>• Включение Jumbo Frames (для магистральных сетей) |

**Способы настройки:**
- **Windows:** «Параметры» → «Сеть и Интернет» → «Настройка параметров адаптера» → Свойства → Протокол IPv4 [[50]]
- **Linux:** файлы `/etc/network/interfaces`, `netplan`, утилиты `ip`, `nmcli` [[53]]
- **Через драйвер:** Панель управления производителя адаптера (Intel PROSet, Realtek Diagnostic Utility)

>  После изменения параметров часто требуется перезагрузка адаптера или системы для применения настроек.
