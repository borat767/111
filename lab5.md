# Лабораторная работа №5  
## Тестирование качества монитора с помощью программных средств

---

### Цель работы
Провести диагностику монитора и выбрать оптимальные параметры цветового отображения.

---

### Теоретические сведения

**MonitorTest** — утилита от разработчиков «PassMark Software», которая позволяет производить различные тестирования монитора.

**Возможности программы:**
1. Поддержка для всех доступных разрешений и глубины цвета
2. Тестирование контрастности
3. Анализ цветопередачи
4. Проверка отображения шрифтов
5. Поддержка большинства типов мониторов
6. Тест экранов Multitouch
7. Проверка конвергенции
8. Поддержка более 300 режимов работы видеокарт

### 3. Назначение тестов

| Тест | Назначение |
|------|-----------|
| **Scale** | Проверка равномерности масштабирования изображения, выявление геометрических искажений и «битых» пикселей. Оценивает плавность градиентов от чёрного к основному цвету. |
| **Gamma** | Анализ гамма-кривых для оценки корректности отображения полутонов и градаций яркости каждого цвета. Позволяет настроить баланс яркости для точной цветопередачи. |
| **Contrast** | Определение способности монитора отображать различия между близкими оттенками, оценка контрастности. Помогает выявить минимальный различимый шаг насыщенности. |

### 4. Результаты цветовых тестов

#### 4.1. Тест Scale: Black → Red, Green, Blue, White

| Цвет | Вывод |

| 🔴 **Red** | Яркость равномерная по всей площади экрана, тёмных и светлых пятен не обнаружено. Битые пиксели: нет. При изменении угла обзора до ±30° переход цвета остаётся плавным, искажений не наблюдается. |
| 🟢 **Green** | Равномерное отображение градиента. Битые пиксели: нет. При отклонении угла обзора более 40° наблюдается незначительное снижение насыщенности в углах экрана. |

> **Общий вывод по тесту Scale:** Монитор демонстрирует равномерную подсветку и качественную цветопередачу. Битые пиксели отсутствуют. Углы обзора соответствуют заявленным характеристикам IPS-матрицы — до 178° без существенных искажений.

#### 4.3. Тест Contrast: Red, Green, Blue, White

**Методика:** Выбрать проценты насыщенности цвета, при котором цвета различимы друг от друга. Оптимальный шаг различимости — **20%**.

| Цвет | Мин. различимый шаг (%) | Оптимальная контрастность |
|------|------------------------|--------------------------|
| 🔴 **Red** | 18% | Высокая — оттенки различимы даже при малом шаге |
| 🟢 **Green** | 20% | Оптимальная — соответствует рекомендуемому значению |
| 🔵 **Blue** | 22% | Средняя — в тёмной зоне требуется шаг 25% для чёткого различения |
| ⚪ **White** | 15% | Отличная — градации серого различимы с высоким запасом |

> **Вывод по тесту Contrast:** Монитор демонстрирует хорошую контрастность, особенно в светлых и средних тонах. Минимальный различимый шаг для большинства цветов составляет 18–20%, что соответствует оптимальному значению. Синий канал требует чуть большего шага в тенях — это характерно для ЖК-матриц с LED-подсветкой.

## Контрольные вопросы

### 1. Виды мониторов

| Тип | Описание | Преимущества | Недостатки |
|-----|----------|-------------|-----------|
| **ЭЛТ (CRT)** | На основе электронно-лучевой трубки | Высокая цветопередача, нет фиксированного разрешения, низкая инерционность | Большие габариты и вес, высокое энергопотребление, мерцание |
| **ЖК (LCD/TFT)** | Жидкокристаллическая матрица с подсветкой | Компактность, низкое энергопотребление, отсутствие мерцания | Ограниченные углы обзора (у TN), возможное засвечивание |
| **IPS** | Улучшенная ЖК-технология с горизонтальным расположением кристаллов | Широкие углы обзора (178°), точная цветопередача, стабильность изображения | Выше стоимость, возможный IPS-glow, чуть ниже контрастность |
| **TN** | Бюджетная ЖК-матрица с вертикальным переключением | Низкая цена, высокое быстродействие (1 мс), высокая частота обновления | Узкие углы обзора, худшая цветопередача, инверсия цветов при наклоне |
| **VA** | Вертикальное выравнивание кристаллов | Высокая контрастность (3000:1 и выше), глубокий чёрный цвет | Средние углы обзора, возможное размытие в динамике, время отклика выше |
| **OLED** | Органические светодиоды, каждый пиксель светится самостоятельно | Идеальный чёрный, бесконечная контрастность, мгновенный отклик, гибкость | Риск выгорания статичных элементов, высокая цена, ограниченная яркость |
| **Mini-LED / QLED** | Улучшенная LED-подсветка с локальным затемнением и квантовыми точками | Высокая яркость (1000+ нит), широкий цветовой охват (DCI-P3), глубокий чёрный | Сложная конструкция, высокая стоимость, возможное blooming |

### 2. Конструкция ЖК-мониторов

```
┌─────────────────────────────────┐
│ 1. Защитное стекло / антибликовое покрытие │
├─────────────────────────────────┤
│ 2. Передний поляризационный фильтр │
├─────────────────────────────────┤
│ 3. Цветовой фильтр (RGB-субпиксели) │
├─────────────────────────────────┤
│ 4. Слой жидких кристаллов │
├─────────────────────────────────┤
│ 5. TFT-матрица (тонкоплёночные транзисторы) │
├─────────────────────────────────┤
│ 6. Задний поляризационный фильтр │
├─────────────────────────────────┤
│ 7. Световод и LED-подсветка (Edge-lit / Direct-lit) │
├─────────────────────────────────┤
│ 8. Рассеивающие и отражающие плёнки │
├─────────────────────────────────┤
│ 9. Корпус, плата управления, разъёмы │
└─────────────────────────────────┘
```

**Принцип работы ЖК-монитора:**
1. **Подсветка** (LED) создаёт равномерный белый свет.
2. **Задний поляризатор** пропускает свет только с определённой ориентацией волн.
3. **TFT-транзисторы** подают управляющее напряжение на каждый субпиксель.
4. **Жидкие кристаллы** под напряжением меняют ориентацию, регулируя количество пропускаемого света.
5. **Цветовой фильтр** разделяет свет на красные, зелёные и синие субпиксели.
6. **Передний поляризатор** завершает формирование изображения, блокируя или пропуская свет.
7. Комбинация интенсивности RGB-субпикселей формирует итоговый цвет каждого пикселя.
